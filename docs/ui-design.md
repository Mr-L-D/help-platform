## 1. 全局设计规范

### 色彩

| 用途   | 色值                   | 说明             |
| ------ | ---------------------- | ---------------- |
| 主色   | `#4F46E5` (Indigo 600) | 按钮、标签、强调 |
| 主色浅 | `#EEF2FF`              | 选中背景、标签底 |
| 成功   | `#10B981`              | 已完成、进行中   |
| 警告   | `#F59E0B`              | 待处理、付费标识 |
| 危险   | `#EF4444`              | 取消、删除       |
| 文字主 | `#1F2937`              | 标题             |
| 文字次 | `#6B7280`              | 描述、时间       |
| 文字弱 | `#9CA3AF`              | 占位提示         |
| 背景   | `#F9FAFB`              | 页面底色         |
| 卡片   | `#FFFFFF`              | 卡片、列表项     |

### 字体

小程序的字体跟随微信默认字体，不额外引入。

| 层级    | 字号           | 用途         |
| ------- | -------------- | ------------ |
| H1      | 20px / bold    | 页面标题     |
| H2      | 18px / bold    | 卡片标题     |
| Body    | 15px / regular | 正文、描述   |
| Caption | 13px           | 辅助信息     |
| Small   | 11px           | 标签、时间戳 |

### 间距

- 页面内边距：16px
- 卡片内边距：16px
- 卡片间距：12px
- 元素间距：8px（紧凑）/ 12px（常规）

**动画状态**

| 状态         | 表现                                          |
| ------------ | --------------------------------------------- |
| 列表加载中   | 底部显示 loading spinner                      |
| 列表为空     | 居中空状态插画 + "还没有求助，去发布第一条吧" |
| 下拉刷新     | 下拉后触发重新加载                            |
| 上滑加载更多 | 触底自动加载下一页                            |
| 网络异常     | toast "网络异常，请下拉重试"                  |

**交互**

- 点击搜索栏 → 弹出搜索框，输入关键词
- 点击类型 Tab → 切换筛选，列表刷新
- 点击分类 → 弹出分类选择面板（底部抽屉）
- 点击卡片 → 跳转详情页
- 底部 "+" 按钮 → 跳转发布页
