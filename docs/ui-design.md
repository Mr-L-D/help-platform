## 1. 全局设计规范

以下规范适用于小程序端和 H5 端，后台端使用 Ant Design 默认主题（见第 3 节）。

### 色彩（来源于 design-system.md）

| 用途     | 色值      | Tailwind    | 说明               |
| -------- | --------- | ----------- | ------------------ |
| 主色     | `#059669` | emerald-600 | 按钮、标签、选中态 |
| 主色深   | `#047857` | emerald-700 | hover / active 态  |
| 主色浅   | `#ecfdf5` | emerald-50  | 选中背景、提示底   |
| 主色边框 | `#a7f3d0` | emerald-200 | 聚焦边框           |
| 强调色   | `#ea580c` | orange-600  | CTA 按钮、付费标识 |
| 强调浅   | `#fff7ed` | orange-50   | 强调背景           |
| 成功     | `#059669` | emerald-600 | 已完成、免费标签   |
| 警告     | `#d97706` | amber-600   | 付费、待处理       |
| 危险     | `#dc2626` | red-600     | 取消、删除         |
| 信息     | `#2563eb` | blue-600    | 进行中、链接       |
| 文字主   | `#0f172a` | slate-900   | 标题               |
| 文字次   | `#64748b` | slate-500   | 描述、时间         |
| 文字弱   | `#94a3b8` | slate-400   | 占位提示           |
| 背景     | `#f8fafc` | slate-50    | 页面底色           |
| 卡片     | `#ffffff` | white       | 卡片、列表项       |
| 边框     | `#e2e8f0` | slate-200   | 默认边框           |

### 字体

| 层级    | 字号    | 字重         | 用途             |
| ------- | ------- | ------------ | ---------------- |
| H1      | 20px    | Bold 700     | 页面/详情标题    |
| H2      | 17px    | SemiBold 600 | 卡片标题         |
| Body    | 15px    | Regular 400  | 正文             |
| Caption | 14px    | Regular 400  | 描述文字         |
| Small   | 12-13px | Regular 400  | 辅助信息、时间戳 |
| Mini    | 11px    | Medium 500   | Badge 内文字     |

行高：正文 1.5-1.7，标题 1.3-1.4。

### 间距（4/8pt 系统）

| Token   | 值   | 用途                   |
| ------- | ---- | ---------------------- |
| space-1 | 4px  | 图标内间距             |
| space-2 | 8px  | 元素间最小间距         |
| space-3 | 12px | 常规间距、卡片间距     |
| space-4 | 16px | 页面内边距、卡片内边距 |
| space-5 | 20px | 模块间距               |
| space-6 | 24px | 大模块间距             |
| space-8 | 32px | 页面级间距             |

### 圆角

| Token     | 值   | 用途                     |
| --------- | ---- | ------------------------ |
| radius-sm | 6px  | 标签、小按钮             |
| radius-md | 10px | 输入框、按钮、卡片内元素 |
| radius-lg | 14px | 卡片                     |
| radius-xl | 20px | 模态框、大面板           |

### 阴影

| Token     | 值                          | 用途           |
| --------- | --------------------------- | -------------- |
| shadow-sm | 0 1px 2px rgba(0,0,0,0.04)  | 卡片默认       |
| shadow-md | 0 4px 16px rgba(0,0,0,0.08) | 悬浮态、下拉   |
| shadow-lg | 0 20px 60px rgba(0,0,0,0.1) | 模态框、大面板 |

### 交互规范

| 规则     | 标准                               | 避免               |
| -------- | ---------------------------------- | ------------------ |
| 触控区域 | ≥44px                              | 小图标无 padding   |
| 按压反馈 | scale(0.98) + opacity 变化 150ms   | 无反馈或布局跳动   |
| 动画时长 | 150-300ms                          | >500ms 阻塞动画    |
| 禁用态   | 降低透明度 0.4-0.5                 | 无视觉区分的禁用   |
| 错误提示 | 就近展示在字段下方，含明确修复指引 | 仅顶部汇总或无提示 |
| Toast    | 3-5 秒自动消失                     | 不消失或抢占焦点   |

**动画状态**

| 状态         | 表现                                          |
| ------------ | --------------------------------------------- |
| 列表加载中   | 底部显示 loading spinner（主色）              |
| 列表为空     | 居中空状态插画 + "还没有求助，去发布第一条吧" |
| 下拉刷新     | 下拉后触发重新加载，顶部刷新指示器            |
| 上滑加载更多 | 触底自动加载下一页，底部 loading              |
| 网络异常     | toast "网络异常，请下拉重试"                  |

**交互**

- 点击搜索栏 → 弹出搜索框，输入关键词回车搜索
- 点击类型 Tab → 切换筛选，列表刷新，选中态下划线（主色 `#059669`）
- 点击分类 → 弹出分类选择面板（底部抽屉）
- 点击卡片 → 跳转详情页
- 底部 "+" 按钮 → 跳转发布页（需登录校验）

### 2.6 小程序组件树

```
components/
├── TaskCard.vue          # 任务卡片（列表用）
│   props: task (TaskBrief)
│
├── StatusTag.vue         # 状态标签
│   props: status (TASK_STATUS)
│
├── RewardBadge.vue       # 赏金标识
│   props: type (REWARD_TYPE), amount?
│
├── FilterBar.vue         # 顶部筛选栏
│   props: typeOptions[], sortOptions[]
│   emits: filter-change
│
├── EmptyState.vue        # 空状态插画
│   props: icon, text
│
├── ImageUploader.vue     # 图片上传
│   props: maxCount (default 9)
│   emits: change
│
├── CategoryPicker.vue    # 分类选择器（底部弹出）
│   props: visible, categories[]
│   emits: select, close
│
├── LoginForm.vue         # H5 登录/注册表单（#ifndef MP-WEIXIN 包裹）
│   props: mode ('login' | 'register')
│   emits: submit
│
└── AuthGuard.vue         # 登录守卫
```
